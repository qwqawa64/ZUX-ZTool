## 概述

ZTool 是一个针对 ZUXOS 的 LSPosed 功能增强模块。

### 游戏优化功能
- CPU 频率修正: 修复游戏服务的 CPU 时钟读取逻辑
- 设备型号伪装: 启用拯救者游戏模式
- 音频控制: 禁用游戏模式音频优化，降低延迟
- 温度管理: 修正 SoC 温度读取
- 防误触管理: 允许自动开启防误触，可选择全部游戏或仅白名单内游戏生效

### 界面定制功能
- 状态栏时钟: 支持格式和样式自定义，可显示秒数并自定义字体大小、字间距、颜色与粗体
- 状态栏网速: 使用双排网速（同时显示上下行速率）或者使用更易读的形式，支持控制刷新间隔，支持隐藏慢速
- 状态栏电量: 使用位于电池图标外部的电量百分比
- 状态栏通知: 自定义通知图标最大显示数量，允许使用原生通知图标
- 锁屏时钟: 自定义锁屏时钟与日期的颜色
- AOD 支持: 强行启用原生 Android 的 AOD 或联想为 OLED 设备设计的息屏显示，并可跳转到联想息屏显示图案设置页
- 随机锁屏签名: 使用自己的一言 API 为锁屏签名添加抽卡的乐趣（笑），支持自定义 API 地址、正则表达式与连通性测试
- 充电信息显示: 在锁屏页面显示实际充电瓦数或握手协议瓦数，可分别显示功率、电压、电流、温度与闪电记号，或使用占位符自定义拼接格式
- 控制中心日期: 允许修改控制中心日期显示格式，并自定义其字体大小、字间距、颜色与粗体
- 控制中心磁贴: 无字模式、磁贴背景色与主次说明文本颜色自定义、圆角半径自定义、隐藏磁贴详情指示按钮
- 控制中心模糊强度自定义
- 竖屏控制中心: 拓宽控制中心面板宽度并按需增加每行磁贴个数
- 音量/亮度条百分比显示，百分比颜色跟随系统取色逻辑
- 滑动条样式: 自定义亮度和音量滑动条的显示方向
- 控制中心长按动效: 磁贴与滑动条使用统一的长按反馈，长按亮度滑动条可呼出亮度详情面板
- 音量详情面板: 长按音量滑动条呼出音量控制台，支持单独调整各应用音量
- 媒体输出弹窗居中: 修正从"媒体输出"磁贴拉起的弹窗贴屏幕左缘的问题
- 回弹延迟修复: 用 AOSP 标准下拉动画替代 ZUI 自定义弹簧动画
- AOSP 长截屏: 借用 AOSP 基础设施让长截屏功能始终可用
- 生物识别: 跳过人脸识别超时限制，关闭生物识别失败震动
- 字体自定义: 允许导入和使用自定义字体
- 充电动画: 允许关闭充电动画、补全充电动画列表以解锁更多内置动画
- 自定义充电动画（竖屏/横屏视频）与充电动画时长
- 桌面动态壁纸: 竖屏与横屏视频分别设置，可选视频显示模式
- 亮灭屏过渡动画，支持自定义动画时长
- 自定义关于设备面板中的一些信息（设备型号、CPU、RAM、ROM、软件版本与设备头图）
- 在应用信息字段显示更多内容，例如包名、Target SDK、首次安装时间、最后更新时间与安装来源，并支持长按复制到剪贴板
- 去除应用图标蒙版: 设置与桌面的第三方图标包图标不再被系统形状二次裁切，可选是否处理动态图标

### 系统更新功能
- 开启本地安装
- 获取增量更新包信息
- OTA 信息拉取: 获取当前版本与新版本的更新日志、下载链接、文件大小与 MD5，并支持一键复制
- 伪装 OTA 版本: 可分别覆盖 OTA 请求中的目标设备 ID 与目标版本名，留空保持系统原值（入口位于 UDS 实时连接引擎页面）
- 关闭系统更新可用时的小红点提示
- 禁止 OTA 自动安装、拦截 OTA 夜间安装弹窗
- 隐藏版本更新通知和角标

### UDS 实时连接引擎功能

> 目标应用为 `com.lenovo.tbengine`，即 ZUI/ZUXOS 的系统更新后台引擎。

- 禁用固件自动下载: 阻止发现新版本后自动下载固件包，不影响手动下载
- 禁用自动安装: 阻止 A/B 无缝后台安装与重启进 Recovery 安装
- 禁用预装应用自动更新: 阻止自动下载并安装预装应用与数据包更新
- 禁用 UPS 推送: 阻止向联想推送服务注册设备与接收更新推送
- 禁用数据上报: 阻止更新埋点上报与推送消息回执
- 本地安装包重签: 让未经联想官方签名的 OTA 包可被安装（需先安装 OTA 证书信任模块）

### ZUI 性能服务

- 屏蔽省电策略云端同步: 仅保留设备内置策略
- 屏蔽游戏策略 OTA 下发: 保留系统内置策略，不再接收 UDS 引擎推送的策略包

### 启动器功能
- 解锁 Dock 栏固定应用数上限
- 允许关闭 Dock 栏
- 关闭任务栏的最近 APP 显示
- 自动拒绝桌面应用推荐文件夹的用户协议，以防被推销莫名其妙的应用
- 应用更新蓝点移除
- 禁止桌面角标提示系统版本更新可用
- 桌面和抽屉无字模式
- 调整划卡杀后台行为，支持配置保护名单
- 最近任务显示内存信息，可选择美化总内存信息与内存扩展显示
- 净化全局搜索，可分别移除搜索推荐与热门搜索卡片
- 允许自定义桌面网格大小
- 扩展桌面网格宽度: 支持正方形网格与左右留白
- 接管图标大小设置
- 大文件夹对齐: 让大文件夹样式更接近主流系统
- 去除桌面图标蒙版
- 启动器内批量卸载 APP
- 所有应用显示小窗入口: 在最近任务菜单中为所有应用显示小窗入口

### 一视界/一视窗功能

- 一视界拓展模块: 以 KSU/Magisk 模块挂载一视界分屏配置，内置 3111 个应用适配策略
- 横屏适配: 支持强制横屏显示
- 去除黑名单限制: 允许所有应用嵌入一视界
- 动态配置: 可手动适配平行视窗界面参数，并查看、查找与追加已适配策略
- 解除小窗 / 分屏白名单限制
- 分屏支持: 绕过应用分屏限制
- 强制小窗 / 强制分屏 / 强制自由小窗 / 强制固定比例小窗
- 关联应用启动时强制以小窗打开
- 悬浮窗口: 增强多窗口管理

### 超级互联功能

- 移除互传开启警告
- 禁止互传自动关闭
- 自动接受互传请求

### 安装器功能

> 开启"启用原生安装器"后，其余安装器选项会被隐藏。

- 启用原生安装器: 使用原生风格的安装器样式
- 移除推荐广告
- 跳过未上架警告页
- 跳过安全扫描
- 不要删除安装包: 拦截安装完成后的删除安装包行为
- 总是在 APP 安装时授予权限

### 安全中心功能

- 禁止病毒提示: 阻止安全中心的各类安全扫描与病毒警报弹窗
- 默认允许 APP 自启
- 允许选择用户根目录: 解除"无法使用此文件夹"的限制

### 输入法功能

> 目标应用为联想 OEM 版搜狗输入法。

- 强制半角符号输出: 中文模式下让列表内的符号以半角上屏，默认与 PC 输入法惯例一致的 `#*-+=`

### 核心破解（仅 Android 16）

- 允许降级安装: 跳过 versionCode 比较
- 绕过签名校验: 跳过安装时的签名与摘要校验
- 绕过签名身份校验: 忽略升级时的签名证书变化，可选择沿用已安装应用的签名记录
- 绕过精确签名比对
- 绕过 sharedUserId 签名限制
- 系统应用允许隐藏 API
- 绕过 resources.arsc 限制: 允许安装 resources.arsc 未满足未压缩与对齐要求的 APK
- 关闭安装校验代理: 安装时不再向校验代理发送验证请求

### 系统框架功能

- 保持屏幕方向为竖屏: 将默认屏幕方向由横屏改为竖屏
- 强制允许截屏: 移除安全窗口标志，解决安全窗口截屏为全黑的问题
- 允许不受信任的触摸
- 关联应用启动: 总是允许关联 APP 启动，并可选择启动时强制以小窗打开
- 禁用高温降低亮度: 取消高温下的亮度压制，避免游戏中降亮度
- 应用列表管理: 默认允许应用获取应用列表，或停用系统自带的"允许获取应用列表"
- 修复深色模式自动切换失效: 清除残留的手动覆盖设置，使"日落到日出"按预期生效

### 杂项

- 杜比音效: 允许在外放时关闭杜比音效
- APP 权限管理器: 允许使用原生 APP 权限管理器
- AI 功能强化: 自定义 AI 全局输入唤醒符
- 禁止访客用户自动创建
- 解除国行 ROM 的语言限制

### 应用界面与维护

- 功能搜索: 全局搜索本应用的功能与设置项，支持拼音匹配与结果定位高亮
- 检查更新: 自动或手动检查 ZTool 新版本，失败时显示具体原因
- 日志: 前台日志采集、导出日志与详细日志开关
- 配置备份还原: 备份配置到文件、从文件恢复配置、恢复默认配置
- 高级选项: 刷新 DexKit 索引、热重载全部模块、重置所有被修改的持久化值、打开首次运行向导
- 杂项工具: 删除系统更新包、联想工程代码入口、获取 9008/联发科深刷救砖包链接
- 首次运行向导: 首次启动时展示用户协议与权限配置向导
- 关于页: 开发者与致谢列表、在 GitHub 查看源码与反馈问题、检查应用更新
- 在设置中显示入口: 在系统设置内显示 ZTool 快捷入口
- 显示全部应用: 在功能面板显示被冻结或卸载的应用
- 主题: Material 3 (Expressive) / Miuix 双风格，支持动态取色、手动种子色、色彩标准与调色板选择、AMOLED 纯黑模式、预测性返回手势、悬浮底栏
- 首页信息: 设备代号、Android 版本、构建版本、内核版本、当前槽位、ROM 地区（PRC/ROW）、Root 实现与框架版本，并提供软重启、重启、Recovery、Bootloader、EDL 等重启入口

> 更多功能正在慢慢更新...

## 使用要求

- 系统: ZUXOS
- 环境: Root + LSPosed 框架

> [!important]
> 和非官方 libxposed API 实现的兼容性尚未经过测试，如果您使用 Vector 等第三方框架并碰到了模块相关问题，我们可能不会响应您的 Issue 。

## 安装步骤

1. 下载 [Releases](https://github.com/qwqawa64/ZUX-ZTool/releases) 中的最新APK文件
2. 安装并授予 Root 权限
3. 在 LSPosed 管理器中启用并勾选作用域 APP
4. 重启系统完成激活
5. 如需使用一视界/平行视窗相关功能，请在 ZTool 设置页内安装内置的一视界拓展模块

## 获取测试版

在项目的 [GitHub Actions](https://github.com/qwqawa64/ZUX-ZTool/actions) 页面可以获取尚未 Release 的测试版本。

可以查看 [更新日志](/更新日志.txt) 了解最新功能变更。通过 [待办列表](/TODOS.md) 查看可能会被添加到新版本中的功能。

## 注意事项

- 本模块仅供学习交流使用，请勿用于非法用途。
- 部分功能需要 Magisk/KernelSU 模块支持。
- 部分修改可能导致设备运行异常，请提前备份数据并确保掌握紧急恢复的方法。
